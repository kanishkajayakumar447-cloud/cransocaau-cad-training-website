# Cransocaau CAD Training Institute Website

A responsive and professional website developed for Cransocaau CAD Training Institute.

## 🚀 Project Overview

This project is a modern responsive website designed to showcase CAD training programs, courses, training modes, student projects, career support, and enquiry information.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- Google Fonts

## 📚 Courses

- CREO
- SolidWorks
- CATIA
- AutoCAD

## ✨ Features

- Responsive navigation
- Mobile-friendly design
- Hero section
- Course showcase
- Training statistics
- Training modes
- Project showcase
- Career support section
- FAQ section
- Contact/enquiry form
- WhatsApp enquiry button
- Course details modal
- Responsive layout for desktop, tablet and mobile
