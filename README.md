# Cransocaau Client Website

## Deliverables
- `index.html` — semantic page structure and content
- `style.css` — responsive visual design
- `script.js` — mobile navigation, course details modal and enquiry-form demo
- `assets/` — place the client's real images here

## Client handover process

1. Replace all placeholder/gradient project visuals with approved client images.
2. Replace the WhatsApp number in `index.html`.
3. Verify the statistics before publishing (500+, 1200+, 300+, 50+).
4. Add the client's real address, email, phone, social links and legal pages.
5. Connect the enquiry form to the client's email/CRM/backend. The current form is front-end demo behavior only.
6. Test on Chrome, Edge, Firefox and mobile screen sizes.
7. Check every navigation link and CTA.
8. Compress images to WebP/JPEG and use descriptive filenames.
9. Add favicon, Open Graph image and final SEO metadata.
10. Deploy using the client's preferred hosting/domain.
