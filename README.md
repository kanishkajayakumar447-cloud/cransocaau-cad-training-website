# Cransocaau CAD Training Institute Website

A modern, responsive and interactive training institute website developed for **Cransocaau CAD Training Institute**.

The website is designed to present courses, help visitors choose suitable training, assess their existing skills, explore projects, compare courses and contact the institute easily.

---

## 🚀 Project Overview

The Cransocaau website provides an interactive digital platform for students who are interested in CAD and technical training programs.

The project focuses on:

- Professional and responsive website design
- Easy course discovery
- Interactive skill assessment
- Course comparison
- Student project showcase
- Trainer information
- Career and placement information
- Student testimonials
- FAQ search
- WhatsApp enquiry
- Training centre location
- Light/Dark mode

---

## ✨ Website Features

### 🎯 V1.0 – Course Finder
Helps users identify a suitable course based on their interests, goals and experience.

### 🧪 V2.0 – Course Skill Assessment
Users can select a course and answer **10 course-specific questions** to understand their current skill level.

Supported courses include:

- CREO
- SolidWorks
- CATIA
- AutoCAD
- NX CAD

The assessment provides:

- Score
- Percentage
- Skill level
- Training recommendation

### 🏗️ V3.0 – Project Gallery
Showcases student projects and practical training work in an organized gallery.

### 📚 V4.0 – Course Comparison
Allows visitors to compare different training programs and understand their differences.

### 👨‍🏫 V5.0 – Trainer Profiles
Displays trainer information and areas of expertise.

### 💼 V6.0 – Career & Placement
Provides information about career support, placement assistance and industry opportunities.

### 📄 V7.0 – Course Brochure
Provides a dedicated section for accessing course brochure information.

### 📱 V8.0 – WhatsApp Enquiry
Provides a quick communication option for course enquiries through WhatsApp.

### 📍 V9.0 – Training Centre Location
Provides location information to help students find the training centre.

### ⭐ V10.0 – Student Testimonials
Displays student feedback and experiences.

### ❓ V11.0 – Smart FAQ
Allows users to search frequently asked questions and quickly find relevant information.

### 🌙 V12.0 – Light / Dark Mode
Allows users to switch between light and dark website themes.
